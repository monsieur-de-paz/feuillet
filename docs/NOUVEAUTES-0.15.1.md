# Feuillet 0.15.1

Les couleurs choisies dans les encadrés sont maintenant visibles, y compris dans leurs titres. Tous les titres respectent désormais les couleurs appliquées manuellement ; leur couleur par défaut reste neutre. Aucun contenu ne doit être recréé.

Cliquer sur l’emoji d’un encadré ouvre le sélecteur habituel avec recherche et variantes. Retirer masque l’emoji ; le bouton + dans l’éditeur permet de le rétablir. Ce bouton ne paraît pas dans la page publique.
