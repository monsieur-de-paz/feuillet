# Feuillet 0.20 — Un accent pour chaque thème

Dans **Réglages & sauvegardes → Apparence générale du carnet**, choisir **Style de l’accent** :

- **Couleur adaptative** : fonctionnement historique. Une couleur choisie en clair produit automatiquement ses variantes sombre et OLED.
- **Monochrome** : gris foncé `#303030` en clair, gris très clair `#E5E5E5` en sombre et `#F5F5F5` en OLED. Les textes des boutons deviennent blancs ou noirs selon leur fond. Le choix existe aussi dans la palette, sous le nom **Monochrome adaptatif**.
- **Personnalisé par thème** : trois sélecteurs séparés pour les accents clair, sombre et OLED. Modifier l’un ne remplace pas les deux autres. Les variantes sombres sont ajustées si leur contraste est insuffisant avec les surfaces du thème. L’aperçu montre les couleurs effectivement utilisées.

Ces options existent aussi dans l’apparence individuelle d’une page. Les visiteurs utilisant le thème système ou les boutons de changement de thème voient la variante correspondante ; ils ne modifient pas le choix de l’auteur.

**Rétablir les couleurs de base** rétablit aussi le mode adaptatif et efface les variantes personnalisées. Les réglages sont sauvegardés automatiquement. Les thèmes existants conservent leur fonctionnement jusqu’à un changement volontaire de style d’accent.

Cette version corrige aussi l’application du thème sauvegardé immédiatement après connexion administrateur. Aucun changement des pages, fichiers ou droits ; aucune migration SQL.
